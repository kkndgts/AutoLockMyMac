# AutoLockMyMac - BLE Device & Apple Watch

一个 macOS 菜单栏应用：根据已配对蓝牙设备的 RSSI 判断设备是否还在电脑附近，离开后执行显示器休眠或启动屏保。

## 已实现

- 主界面：直接选择判断设备、直接设置具体 RSSI 门限、查看当前 RSSI 和监控状态。
- 可调扫描间隔：支持设置采样周期，范围 `15`～`600` 秒。
- 状态栏常驻：关闭主窗口后，应用继续留在状态栏的小锁图标中运行。
- 灵敏度预设：
  - `近距离`：`-60 dBm`，连续 `2` 次离开样本判定离开
  - `均衡`：`-72 dBm`，连续 `3` 次离开样本判定离开
  - `宽松`：`-82 dBm`，连续 `5` 次离开样本判定离开
  - `自定义`：可手动设置 RSSI 门限和连续离开样本数
- 离开动作：
  - `关闭屏幕并锁定`（需在 macOS 中设为显示器关闭后立即需要密码）
  - `开启屏保`
- 唤醒后会自动重新检测一次；在屏保模式下，如果设备判定仍在附近，会尝试退出 `ScreenSaverEngine`。

## 当前限制

- macOS 真正的登录锁屏界面不能被普通第三方应用自动解锁。
- 如果系统设置为“睡眠或屏保后立即需要密码”，最终解锁仍然由 macOS 自己处理。
- RSSI 读取对蓝牙设备类型比较挑剔。当前版本更适合选择 Apple Watch配合比较合适，Apple Watch可以实现离开锁屏，靠近之后需要解锁通过MacOS原有的Apple Watch解锁功能实现。 

## 构建可双击运行的 App

```bash
./scripts/build_app.sh
```

生成结果：

```text
dist/AutoLockMyMac.app
```

## 开发运行

```bash
swift build
swift run
```

也可以直接在 Xcode 中打开这个目录对应的 Swift Package。
